# Оксана Вдовина — фуршеты и десерты

Сайт-витрина с корзиной на React 18 + TypeScript + Vite, анимации — framer-motion, роутинг — react-router v6.

## Запуск

```bash
npm i
npm run dev      # http://localhost:5174
npm run build    # проверка типов + сборка в dist/
npm run preview  # просмотр собранной версии
```

## Деплой

- **Vercel** — импортировать репозиторий, всё настроено в `vercel.json` (SPA-редиректы).
- **Netlify** — build command `npm run build`, publish directory `dist`; редиректы в `public/_redirects`.
- Любой статический хостинг: залить `dist/` и настроить отдачу `index.html` на все пути.

## Страницы

`/` главная · `/menu` меню с фильтрами и поиском · `/product/:slug` карточка блюда ·
`/boxes` готовые боксы · `/constructor` конструктор фуршета · `/cart` оформление (3 шага) ·
`/thanks` · `/about` · `/delivery` · `/contacts` · 404.

## Где менять данные

- `src/data/site.ts` — телефон, WhatsApp, ВК, адрес, часы, условия доставки.
- `src/data/menu.ts` — категории, блюда, цены, вес, фото, бейджи, боксы.
- `src/styles/global.css` — цвета и шрифты (переменные в `:root`).

Заказ оформляется в корзине и уходит готовым сообщением в WhatsApp. Корзина хранится в localStorage.

## Анимации «посмотреть товар»

Быстрый просмотр (клик по фото в карточке), лупа и полноэкранная галерея, 3D-наклон,
«распаковка» бокса, «на столе» (раскладка на блюде), камера-зум по ракурсам,
конструктор с живым блюдом. Для `prefers-reduced-motion` анимации упрощаются.

## Что проверить перед запуском

- Фото подгружаются с CDN `media.dodostatic.com` — лучше перенести их в `public/` или на свой CDN.
- Тексты FAQ, условия доставки и оплаты, город и минимальный заказ.
- Номер WhatsApp (сейчас совпадает с телефоном).
- Домен в `index.html` (canonical, og:url) и JSON-LD.
